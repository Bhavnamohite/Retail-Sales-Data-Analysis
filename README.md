# 📊 Retail Sales & Profit Excel Dashboard

An interactive Excel dashboard designed to analyze **$1.92M in total sales** and **$247K in profit**. This project transforms raw transactional data into actionable business insights regarding regional performance, product categories, and customer value.

## 🔍 Key Insights Discovered
* **Top Performance:** Technology is the primary profit driver, peaking significantly in 2023.
* **Product Winners:** Phones and Chairs dominate total sales volume across all categories.
* **Regional Hubs:** California and New York stand out as the two highest-performing geographic markets.

## 🛠️ Features & Excel Techniques Used
* **Advanced Pivot Tables & Pivot Charts:** Dynamically aggregates sales data across years, months, and states.
* **Interactive Slicers:** Connected to all visuals to allow seamless filtering by Year, Month, and Category.
* **KPI Cards:** High-level summary cards using custom formatting for quick executive review.
* **Data Visualization Best Practices:** Clean grid layout, customized donut chart representation, and structured horizontal bar charts for ranking.
